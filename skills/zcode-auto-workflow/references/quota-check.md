# 额度检查：界面路径与判读

软件界面会变，坐标不可硬编码；坐标只作参考，每次先截图再点。

## 三步检查

### 第 1 步：主界面找赠送卡片

- 主界面/新建任务页上若有醒目的「送 Token / 赠送 / 活动」卡片，读出**数量 + 到期时间**并截图。
- 没有就是没有，不要翻二级页面找。

### 第 2 步：头像菜单

- 点左下角用户头像或名称，弹出菜单（常见项：界面语言、界面主题、界面模式、界面缩放、使用统计、升级、邀请好友、断开连接）。
- 看菜单里有没有赠送/奖励入口；Esc 关闭菜单最稳（点空白处经常关不掉）。

### 第 3 步：设置 → 模型/配额页

- 设置入口在侧栏底部图标行；点开后左侧是图标列表，找到「模型设置」（常见是第三项）。
- 右侧是供应商/套餐列表，选个人套餐那一栏 → 上下滚动看全部额度。
- 记录每一块：总额度池（总量、已用、到期时刻）与每日额度（每天重置的小份，各自到期时刻）。

## 判读口径

| 看到什么 | 含义 |
|---|---|
| 整体额度池（亿级、固定到期） | 主要可用额度，比较耐用；到期前用掉 |
| 每日额度（每天重置的小份） | 补充额度，重置频繁，别当主力 |
| 醒目的赠送卡片 | 活动额度，先领再算 |

结论三选一：

1. **有大额度**：领取并记录，继续推进。
2. **整体额度仍充裕**：按计划继续到收尾。
3. **额度告罄 / 没有任何赠送**：收工，删掉为夜班设的巡检与收尾定时。

## 报告格式

```
额度：<整体额度 已用/总量，到期时刻>；<每日额度 各项>
赠送：<有/无 + 数量与到期>
结论：<继续 / 收尾>
```
