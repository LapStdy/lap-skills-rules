# ZCode 界面操作

界面坐标会漂，所有点击以当场截图为准；任何一次点击后都截一张，宁可多一张图，不要凭记忆连点。

## 前置：窗口与前台

1. 列出窗口，确认 ZCode 标题与位置。
2. 前台被别的应用占据时，先用 AppActivate 把 ZCode 提到前台再操作；提不到就带「容忍焦点」继续，并在回执里注明。
3. 记住坐标用**窗口左上角偏移**，不要用屏幕绝对值：窗口一挪，绝对值就废。

## 派卡五动作

1. **开新任务**：点侧栏「新建任务」（或快捷键）。判据：出现空输入框与项目芯片。
2. **选项目**：先点项目芯片选目标工作区，**再**输入内容（选项目会清空输入框）。判据：项目芯片显示目标项目与分支。
3. **选模式**：点输入框下方模式芯片，选「完全访问」。判据：芯片标签变为「完全访问」。该选择不跨任务保留，每个新任务都要重选。
4. **粘卡文并发送**：点输入框的**可编辑行**（不是底部的模式/模型行），粘贴卡文，回车发送。判据：会话标题变成卡文首行、出现「工作中」、侧栏任务列表出现该任务。
5. **挂监听**：按 `references/watcher.md` 起只读轮询作业，或建定时唤醒。判据：作业在跑、能报出任务标题与状态。

## 界面坐标纪律

- 点输入框要点**可编辑那一行**；点到下方模式/模型行不会获得焦点，粘贴会丢。
- 头像菜单、下拉菜单、设置弹窗用 Esc 关闭最稳；点空白处有时关不掉。
- 设置入口在侧栏底部图标行，具体第几个图标以截图为准；进设置后逐级点，每一步截图确认。
- 窗口位置变化后必须重新截图，再按图找。

## 常见坑

| 现象 | 原因 | 改法 |
|---|---|---|
| 粘贴后输入框仍空 | 点到了模式/模型行 | 重新点可编辑行再粘 |
| 粘贴内容消失 | 选项目发生在粘贴之后 | 先选项目再粘 |
| 模式回到「自主模式」 | 选择不跨任务保留 | 每个新任务重选完全访问 |
| 模型停在等待审批 | 模式不是完全访问 | 新任务改选完全访问；已卡住的停掉重派 |
| 窗口抢不到前台 | 别的应用持有前台 | 先 AppActivate，再容忍焦点操作 |
| 任务长时间无新提交 | 疑似卡死 | 看是否在等输入；不是就停掉、保留 worktree、重派 |
| 找不到「新建任务」 | 侧栏折叠或窗口太窄 | 展开侧栏，或按快捷键；以截图为准 |

## 停卡与重派

- 卡死或方向错了：先在界面停掉任务，**保留 worktree 与分支**（可能有可救的半成品）。
- 重派时在卡文里点名「沿用已有 worktree 与分支，先 `git log` 看已有提交，不要重做已完成部分」。
- 停掉的旧任务不要删记录，留作事后追溯；侧栏里同名任务以创建时间为准区分。

## 查账号菜单与额度入口

- 账号菜单：点左下角头像/名称；菜单项常见界面语言、界面主题、界面模式、界面缩放、使用统计、升级、邀请好友、断开连接；Esc 关闭。
- 额度：侧栏底部设置（齿轮）→ 左侧模型设置 → 套餐列表 → 上下滚动。具体路径见 `references/quota-check.md`。
