# 会话轮换（上下文到阈值时换新会话）

目的：长会话上下文膨胀后换一个干净会话继续，接续靠落盘而不是靠记忆。

## 第 0 步：先落盘

1. 写今日日志一条（进展、门禁、在跑卡片）。
2. 写交接账本（四段式）：任务状态 / 目标 / 已试方案与失败原因 / 进度与下一步。下一步必须是可直接执行的第一步（带路径或命令）。
3. 确认账本里四项齐全：main 位置、在跑卡片（分支 + worktree）、未合分支、下一步。

## 第 1 步：新建会话

- 界面左侧栏展开工作区；把鼠标悬浮到目标工作区那一行，行尾出现「+」按钮；点击即新建该工作区的会话。
- 记录「+」按钮坐标；窗口位置会变，下一次直接按坐标点，点不中再悬浮重找。
- 新建后主视图变成空白欢迎页，原会话仍在列表里继续跑，切回原会话点列表行即可。

## 第 2 步：发交接提示词

把下面模板填好发进新会话（一段话，自包含）：

```
继续 <项目> 的 ZCode 自动工作流。先读以下三份，读完先复述状态，再开始：
1) <项目> 交接文档 <绝对路径>
2) 白板与最新交接账本（memory 工具读 plan/handoff）
3) 今日日志

当前状态速览（以账本为准，若有冲突以账本更新）：main=<commit>；在跑卡片 <卡名/分支/worktree>；
未合分支 <分支>；下一步 <一步动作>。

工作约定：
- 每批最多 <N> 张卡，一卡一 worktree；卡文尾部必须带质量审查要求与「做完停手不合并」。
- 完成即「复核 → 串行门禁 → 合并 → 清理 → 再派」；门禁串行跑，不并行。
- 用后台只读轮询作业盯任务终态（脚本 <路径>），任务到终态就退出并叫醒本会话。
- 在本会话里重建这些定时：<巡检间隔>、<收尾时刻>、<额度检查时刻>。
- 上下文到 <阈值> 再按同样的轮换流程换会话，先落盘再换。
```

## 第 3 步：新会话自检

- 能复述 main、在跑卡片、未合分支、下一步四项。
- 定时已重建、监听已挂。
- 旧会话留在列表里不再发消息（只读备查）。

## 常见坑

| 现象 | 原因 | 改法 |
|---|---|---|
| 新建后找不到「+」 | 悬浮才显示 | 悬浮工作区行再找 |
| 点「+」没反应 | 点到了同一行的「…」或会话名 | 以截图为准点行尾圆形「+」 |
| 新会话不知道上下文 | 交接提示词没写全 | 提示词必须自包含：路径、commit、在跑卡片、定时 |
| 旧会话仍被定时唤醒 | 定时是会话级的，旧会话自己也有一份 | 换会话后把旧会话的定时删掉 |

## 切换与坐标

- 新建后主视图变成空白欢迎页；原会话继续在列表里跑，点侧栏会话行即可切回（首行通常是当前会话）。
- 空会话不发消息不会留下记录，可以放心点「+」试探。
- 记坐标用**窗口左上角偏移**而不是屏幕绝对值：窗口一挪绝对值就废，偏移还能复用。
- 点不中就重新截一张窗口图，按图找，不要凭记忆连点。
