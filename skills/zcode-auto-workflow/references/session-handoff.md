# 会话交接（DSH 主控会话换新）

目的：值守中途主控上下文接近阈值时，换一个干净的 DSH 会话继续；状态靠落盘，不靠记忆。

## 先分清两条「新建」

值守时有两个界面、两种「新建」，外观相近，后果完全不同：

| 要达成 | 应用 | 点哪里 | 完成后必须看到 |
|---|---|---|---|
| 派一张卡给执行者 | ZCode | 侧栏「新建任务」（Ctrl+N）→ 点项目芯片选项目 → 模式选「完全访问」→ 改模型与思考强度 → 粘卡文 → 回车 | ZCode 侧栏任务列表多一行、标题是卡文首行；真源库 `session.permission` 为 `{"mode":"yolo"}` |
| 主控会话换新（接续） | DeepSeek Harness（DSH） | 侧栏顶部「新会话」；要点名工作区时，悬浮该工作区行再点行尾「+」 | DSH 主视图变空欢迎页；该工作区下多一行新会话 |
| 切回某个执行者任务 | ZCode | 侧栏任务列表点任务行 | 主视图回到该任务的对话 |
| 切回某个主控会话 | DSH | 工作区下点会话行 | 主视图回到该会话 |

判据：**卡永远在 ZCode，会话永远在 DSH。** 两个侧栏都有「项目 / 工作区」列表、都靠悬浮露出「+」，点错不报错，只留下两种空转：

- 在 ZCode 点「新建任务」去做接续 → 得到一张没人看的空执行者任务，主控上下文照旧满。
- 在 DSH 点「新会话」去派卡 → 执行者收不到卡，卡文变成主控自己的一段话。

三处硬区别，任一处能认出就不算串台：

| | ZCode | DSH |
|---|---|---|
| 窗口标题 | `ZCode` | `<会话标题> — DeepSeek Harness` |
| 侧栏词 | 新建任务、任务列表、项目 | 新会话、工作区、会话 |
| 后续动作 | 真源库校验权限与模型 | 发交接提示词、重建 watcher 与定时 |

## 第 0 步：先落盘（落不了就不换会话）

1. 今日日志一条：进展、门禁结论、在跑卡。
2. 交接账本四段式，四项齐全：main 位置、在跑卡（分支 + worktree）、未合分支、下一步。
3. 「下一步」写成可直接执行的第一步，带路径或命令。
4. 账本里引用的路径与提交先核一遍：`Test-Path`、`git rev-parse --short HEAD`。

判据：假设这个会话现在消失，下一个会话照账本能直接开工。

## 第 1 步：在 DSH 新建会话

- 会话标题按 `接续#<序号> · <项目> · <日期>` 命名，侧栏一眼能认出哪一行是主控接续。
- 入口：侧栏顶部「新会话」；要点名工作区时悬浮该工作区行、点行尾「+」。判据：主视图变空欢迎页。
- 原会话仍在列表里继续跑；空会话不发消息不留记录，可以点开探路。
- 点不中：重新取一张窗口帧按图找，不要凭记忆连点。

## 第 2 步：发交接提示词

填好下面模板，发进 DSH 新会话（一段话，自包含）：

```
继续 <项目> 的 ZCode 自动工作流。先读以下三份，读完先复述状态，再开始：
1) <项目> 交接文档 <绝对路径>
2) 白板与最新交接账本（memory 工具读 plan/handoff）
3) 今日日志

当前状态速览（以账本为准，若有冲突以账本更新）：main=<commit>；在跑卡片 <卡名/分支/worktree>；
未合分支 <分支>；下一步 <一步动作>。

工作约定：
- 每批最多 <N> 张卡，一卡一 worktree；卡文尾部带质量审查要求与「做完停手不合并」。
- 派卡在 ZCode 窗口点「新建任务」完成；本会话负责盯卡、复核、串行门禁、合并、清理与记账。
- 完成即「复核 → 串行门禁 → 合并 → 清理 → 再派」；门禁串行跑，不并行。
- 用后台只读轮询作业盯任务终态（脚本 <路径>），任务到终态就退出并叫醒本会话。
- 在本会话里重建这些定时：<巡检间隔>、<收尾时刻>、<额度检查时刻>。
- 上下文到 <阈值> 再按同样的轮换流程换会话，先落盘再换。
```

## 第 3 步：新会话自检

- 能复述 main、在跑卡片、未合分支、下一步四项。
- watcher 作业与到点收尾定时已重建（会话级，不跟过去）。
- 旧会话留在列表只读备查，不再发消息；旧会话里的定时已删。

## 常见坑

| 现象 | 原因 | 改法 |
|---|---|---|
| 接了续却还在旧会话里干活 | 新会话没发过消息，认不出来 | 按 `接续#N` 命名在侧栏找到那一行点进去 |
| 新建后找不到「+」 | 悬浮才显示 | 悬浮目标工作区行再找 |
| 点「+」没反应 | 点到同一行的「…」或会话名 | 以窗口帧为准点行尾圆形「+」 |
| 新会话不知道上下文 | 交接提示词没写全 | 自包含：路径、commit、在跑卡、定时 |
| 旧会话仍被定时唤醒 | 定时是会话级的 | 删旧会话的定时 |
| 卡派到了 DSH、会话开在了 ZCode | 两个侧栏外观相近 | 先看窗口标题：ZCode 派卡，DSH 交接 |

## 坐标纪律（跨两个窗口）

- 按窗口名分别取帧：`screen_view(window="ZCode")`、`screen_view(window="DeepSeek Harness")`；不复用另一个窗口的帧，两个窗口的尺寸与原点都不同。
- 记坐标用窗口左上角偏移，不用屏幕绝对值：窗口一挪，绝对值就废。
- 每次点击后重取一帧再决定下一次点击；指针悬停在按钮上会冒出提示小窗，取帧前先移开。
