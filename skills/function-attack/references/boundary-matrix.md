# 边界矩阵与错误契约

> 用途：步骤 1–2 的检查表。先按维度列「输入域」，再写测试；不要凭感觉挑几个输入。

## 1. 输入域维度表（模板）

| 维度 | 合法范围 | 边界值 | 非法/负向值 | 契约期望 | 用例 | 结果 |
|---|---|---|---|---|---|---|
| 数值 | 0..1e9 | 0、1、上界、上界+1 | 负数、小数、NaN、Inf | 抛 ValueError | … | ✅/❌ |
| 字符串 | 1..64 字符 | 空、1 字符、64、65 | 空白、控制字符、超长 | 抛 ValueError | … | ✅/❌ |
| 类型 | str | — | None、int、bytes、bool | TypeError | … | ✅/❌ |
| 集合 | 非空 | 1 个、重复、最大 | 空、含 None | 空返回空列表 | … | ✅/❌ |

**判据**：每个高风险维度至少 1 条正常 + 1 条负向；不测的维度写理由。

## 2. 通用维度清单

| 维度 | 要想到的边界/负向值 |
|---|---|
| 数值 | 0、-0、±1、MIN/MAX、溢出边界、NaN、±Inf、精度极限、布尔当整数 |
| 字符串 | 空串、单字符、超长、空白、换行（LF/CRLF）、BOM、非法 UTF-8、emoji/组合字符、大小写、格式符（% 与花括号）、NUL |
| 集合/序列 | 空、单元素、重复元素、超长、嵌套、含 None、生成器 vs 序列、原地修改 |
| 布尔/枚举 | 全部枚举值、未知值、非法枚举、字符串冒充枚举 |
| 空值/类型 | None/null、零值、空对象、Optional 的 None 路径 |
| 时间 | 时区、夏令时、闰年、边界日期、时钟回拨、naive 与 aware 混用 |
| 文件/路径 | 不存在、无权限、空文件、超大、符号链接、Windows 保留名/长路径 |
| 网络/外部 | 超时、连接拒绝、半包、重定向、非 2xx、畸形响应 |
| 状态/并发 | 竞态、重入、死锁、取消/中断、重复调用（幂等） |
| 资源 | 打开未关闭、临时文件残留、锁未释放、内存增长 |

## 3. Python 常见坑

- **鸭子类型**：类型注解不拦截运行时，`None`/错误类型可能到深层才炸；在公共边界显式校验。
- **falsy 区分**：`None`、`""`、`0`、`[]`、`False` 都可能被 `if not x` 混为一谈；契约要写清「空」指哪个。
- **bool 是 int 子类**：`isinstance(True, int)` 为真；数值校验要排除 bool。
- **NaN**：`nan != nan`，集合/排序/比较都会出意外；用 `math.isnan`。
- **浮点**：`0.1 + 0.2 != 0.3`；金额/精度场景用 Decimal 或容差比较。
- **datetime**：tz-aware 与 naive 不能直接比较；`datetime.now()` 依赖本地时区。
- **str/bytes**：混用时抛 TypeError；编码/解码错误要按契约处理。
- **Unicode**：组合字符、全角数字、不同 normalization 形式可能让「看起来一样」的输入走不同分支。
- **可变默认参数**：`def f(items=[])` 在多次调用间共享；这是缺陷不是边界。
- **递归深度**：超长嵌套输入可能触发 RecursionError，契约没写就是未定义行为。

## 4. 错误契约五件事

1. **类型**：抛什么异常 / 返回什么错误码；可预期失败与不可预期失败要分开。
2. **消息**：包含关键字段与出错值（可 grep、可定位），但测试只断言关键词，不断言整段文案。
3. **副作用**：失败时是否写了一半、扣了款、删了文件；要么原子，要么可回滚。
4. **资源清理**：文件/连接/锁/临时目录是否释放（可用 try/finally 或上下文管理器验证）。
5. **重试语义**：失败后能否安全重试；不可重试要显式说明。

**禁止**：用值域内的哨兵表示失败（例如合法值 -1 与失败 -1 撞车）；同一模块混用「返回 None / 抛异常 / 返回错误码」。**推荐**：可预期失败返回空值或结果类型，不可预期抛异常，全模块一致。

## 5. 故障注入（按需）

| 层级 | 注入什么 | 手段 |
|---|---|---|
| 依赖级（优先） | DB/HTTP/文件/时钟失败 | 依赖注入 + fake/stub；`pytest monkeypatch` 仅用于不可注入的第三方边界 |
| 环境级 | 环境变量缺失、目录不可写、权限、磁盘满 | `monkeypatch.delenv/setenv`、`tmp_path`、只读目录 |
| 输入级 | 非法类型/空值/极值/畸形编码 | 边界表 + 属性测试生成 |

**判据**：注入后按契约失败（正确异常/错误码、无脏数据、可重试），不是崩溃或静默吞掉。

## 6. 一个通用反例模板

- 输入：`""`（空串）
- 期望：按契约抛 `ValueError`，消息含「empty」
- 实际：返回 `-1`（与合法值 -1 无法区分）
- 复现：`python -c "from mod import parse; print(parse(''))"`
- 影响：调用方无法区分「解析失败」与「合法负值」，错误被静默传播。
