# 攻击报告模板

> 复制后按实际内容填写；没有的项写「不适用 + 理由」，不要留空。

```text
# 攻击报告：<module>::<function>

## 目标与契约
- 目标：<path:line>
- 风险级别：<低/中/高>；时间预算：<N min>
- 契约：
  - 输入域：<合法输入与前置条件>
  - 输出保证：<返回什么、范围/不变量>
  - 错误类型：<失败返回什么 / 抛什么异常>
  - 副作用：<无 / 写哪里 / 幂等性>
  - 线程/重入假设：<...>
- 调用点：<file:line，输入来源、输出去向>
- 现有测试：<路径与基线结果>

## 8 步结论
| # | 步骤 | 结论 | 证据 |
|---|---|---|---|
| 0 | 契约与调用点 | ✅/❌ | <file:line、命令输出> |
| 1 | 输入域/边界 | ✅/❌/不适用 | <维度表摘要、用例数> |
| 2 | 错误契约 | ✅/❌ | <异常类型/消息/副作用/清理> |
| 3 | 属性 | ✅/❌ | <属性列表与结果> |
| 4 | 变异 | ✅/❌ | <抽样数/统计/分数> |
| 5 | fuzz | ✅/❌/不适用 | <工具/种子/时长/崩溃> |
| 6 | 差分/蜕变 | ✅/❌/不适用 | <第二实现/MR/不一致> |
| 7 | 固化+稳定性 | ✅/❌ | <回归用例、重复次数> |

## 最小反例
### 反例 1
- 输入：<最小输入>
- 期望：<契约要求>
- 实际：<结果或异常，含类型与关键消息>
- 复现：<可直接执行的命令>
- 影响：<谁会受影响>

## 变异
- 工具/方式：<mutmut / 手工注入>
- 范围：<文件:行>；抽样：N
- 结果：killed X / survived Y / timeout Z / unviable U → 分数 P%
- 口径：<timeout 是否计入 detected；unviable 处理>
- 存活与处置：
  - <变异位置与改法> → <补断言/等价/超时/接受>（理由）

## fuzz / 差分 / 蜕变
- <做了/未做，写清工具、种子、时长、结果、降级原因>

## 未覆盖风险
1. <风险>：为什么没覆盖、建议下一步
2. ...

## 结论
<一句话：做了哪几步、发现什么、还剩什么风险；不要写「测试全绿所以没问题」>
```
